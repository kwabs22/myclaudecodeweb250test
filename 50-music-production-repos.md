## Digital Audio Workstations (DAWs)

### 1. Stargate DAW
**Repository:** `stargatedaw/stargate`
**Description:** Innovation-first digital audio workstation, instrument and effect plugins, wave editor. All-in-one DAW and plugin suite designed for EDM production with unique features.
**Tech Stack:** Python, C++
**Key Features:** Built-in synthesizers, effects, wave editor

### 2. Anthem
**Repository:** `anthem-audio/anthem`
**Description:** Modern digital audio workstation for Windows, macOS, Linux, and web. Active development in 2024-2025.
**Tech Stack:** Flutter UI, C++ engine
**Key Features:** Cross-platform, sequencer, live audio graph, IPC state synchronization

### 3. GridSound
**Repository:** `gridsound/daw`
**Description:** Free browser-based digital audio workstation following the Web Audio API.
**Tech Stack:** JavaScript, Web Audio API
**Key Features:** Browser-based, no installation required, pattern-based sequencer

### 4. WebDAW
**Repository:** `ai-music/webdaw`
**Description:** Portable music composition and production environment running in browsers using Web Audio and Web MIDI APIs.
**Tech Stack:** JavaScript, Web Audio API, Web MIDI API
**Key Features:** Browser-based, MIDI support, portable

### 5. Ardour
**Repository:** `Ardour/ardour`
**Description:** Professional-grade digital audio workstation for recording, editing, and mixing.
**Tech Stack:** C++
**Key Features:** Multi-track recording, mixing, non-destructive editing

## Synthesizers & Sound Design

### 6. Surge XT
**Repository:** `surge-synthesizer/surge`
**Description:** Open-source synthesizer with 12 oscillator algorithms including wavetable, FM, and more. Previously commercial Vember Audio software.
**Tech Stack:** C++
**Key Features:** 3 oscillators per scene, extensive modulation, cross-platform VST/AU/LV2

### 7. Vaporizer2
**Repository:** `VASTDynamics/Vaporizer2`
**Description:** Hybrid wavetable additive/subtractive synthesizer and sampler workstation.
**Tech Stack:** C++
**Key Features:** VST2/VST3/AU/AAX/CLAP/LV2, standalone version, GPL3 license

### 8. Firefly Synth
**Repository:** `sjoerdvankreel/firefly-synth`
**Description:** Semi-modular synthesizer and FX plugin for Windows, Linux, and Mac.
**Tech Stack:** C++
**Key Features:** VST3/CLAP formats, complex sound design capabilities

### 9. Vital
**Repository:** `mtytel/vital`
**Description:** Spectral warping wavetable synthesizer.
**Tech Stack:** C++
**Key Features:** Advanced wavetable synthesis, visual feedback, modern UI

### 10. Dexed
**Repository:** `asb2m10/dexed`
**Description:** Multi-platform, multi-format plugin synth closely modeled on Yamaha DX7.
**Tech Stack:** C++
**Key Features:** DX7 emulation, FM synthesis, VST/AU

## MIDI Tools & Sequencers

### 11. Seq66
**Repository:** `ahlstromcj/seq66`
**Description:** Seq24-based live MIDI looper/editor with pattern banks, triggers, and piano roll.
**Tech Stack:** C++
**Key Features:** NSM support, Linux/Windows/FreeBSD, PDF manual

### 12. PianoRoller
**Repository:** `johndpope/PianoRoller`
**Description:** Piano roll VST allowing musicians to use piano roll sequencer inside their DAW.
**Tech Stack:** C++, JUCE
**Key Features:** Multiple presets, DAW automation

### 13. MIDI Sequencer (Web)
**Repository:** `mobyvb/midi-sequencer`
**Description:** Web app for uploading MIDI files, editing with piano roll, and downloading.
**Tech Stack:** JavaScript
**Key Features:** Browser-based, piano roll editor, MIDI file I/O

### 14. QMidiArp
**Repository:** `emuse/qmidiarp`
**Description:** Advanced MIDI arpeggiator, sequencer, and LFO.
**Tech Stack:** C++, Qt
**Key Features:** LFO, step sequencer, arpeggiator modules

### 15. Aria Maestosa
**Repository:** `ariamaestosa/ariamaestosa`
**Description:** MIDI sequencer/editor with score, keyboard, guitar, drum, and controller views.
**Tech Stack:** C++
**Key Features:** Multiple notation views, user-friendly interface
