## Top Comprehensive Platforms

### 1. LibreLingo
**Repository**: kantord/LibreLingo
**Stars**: 2.5k | **Language**: Python
**Description**: A community-owned language-learning platform with flashcards and spaced repetition capabilities. Open-source alternative to Duolingo with AGPL-3.0 license guaranteeing freedom to run, study, share, and modify.
**Key Features**: Community content creation, gamification, spaced repetition

### 2. LinguaCafe
**Repository**: simjanos-dev/LinguaCafe
**Stars**: 1.2k | **Language**: Vue
**Description**: Self-hosted software that helps language learners read foreign languages with integrated dictionary lookups and vocabulary tracking.
**Key Features**: Self-hosted, reading-focused, vocabulary management

### 3. jidoujisho
**Repository**: arianneorpilla/jidoujisho
**Language**: Dart/Flutter
**Description**: A full-featured immersion language learning suite for mobile. Originally built for the Japanese language learning community. Video player, reading aid, dictionary and card creation toolkit.
**Key Features**: AnkiDroid integration, YouTube support, Jellyfin streaming, multimedia flashcards

### 4. Hanabira.org
**Repository**: tristcoil/hanabira.org
**Description**: Free and open-source Japanese and Korean language learning portal with self-hosting capability. JLPT N5-N1 preparation.
**Key Features**: Text parsing, grammar explanations, YouTube immersion, kanji mnemonics, MIT License

## Getting Started Recommendations

**For Beginners**:
- Start with **LibreLingo** for structured courses
- Use **Anki decks** (JLPT, COCA) for vocabulary building
- Try **LinguaCafe** for reading practice

**For Intermediate Learners**:
- Use **asbplayer** or **mpvacious** for sentence mining from content you enjoy
- Practice speaking with **SpeechGPT**
- Read extensively with **LUTE** or **lwt**

**For Advanced Learners**:
- Implement immersion workflows with **jidoujisho** (mobile) or **VocabSieve** (desktop)
- Use **Journaly** for writing practice with native corrections
- Create custom vocabulary systems with **Vocascan**

**For Japanese Learners**:
- **Yomitan** (browser extension) + **Memento** (video) + **Anki JLPT decks** = Complete toolkit

**For Developers**:
- Check **awesome-language-learning** for technical libraries
- Use **basic-vocabulary-word-lists** for app development
- Explore **Microsoft AI Lab** for AI/ML language tools

This collection represents the vibrant open-source language learning ecosystem on GitHub. **Research methodology**: Repositories were curated from GitHub Topics (language-learning, vocabulary-learning, flashcards, foreign-language, language-learning-game, spaced-repetition, pronunciation), awesome lists, and web searches conducted in November 2025.
