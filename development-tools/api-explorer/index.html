Free API Explorer

The 114 APIs described in the repository's popular, information and additional documents, sorted by how much sign-up each needs. For the ones that need none, press Try to call the API live from your own browser and see what comes back.

Free to use. Calls go from your browser straight to each API: there is no key, no account and no server of ours in between, so nothing is billed to anyone. Keyed and OAuth APIs are never called here.

The endpoints were written by hand from each API's own documentation, because the repository documents hold search-term ideas, not URLs. This page is how you find out which still work. A browser reports "blocked" and "offline" the same way, so a failure can mean the API sends no cross-origin permission, is down, or was moved.
