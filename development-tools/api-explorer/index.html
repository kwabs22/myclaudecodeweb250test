Free API Explorer

The 114 APIs described in the repository's popular, information and additional documents, sorted by how much sign-up each needs. For the ones that need none, press Try to call the API live from your own browser and see what comes back.

Free to use. Calls go from your browser straight to each API: there is no key, no account and no server of ours in between, so nothing is billed to anyone. Keyed and OAuth APIs are never called here.

The endpoints were written by hand from each API's own documentation, because the repository documents hold search-term ideas, not URLs. This page is how you find out which still work. A browser reports "blocked" and "offline" the same way, so a failure can mean the API sends no cross-origin permission, is down, or was moved.

Popular Hugging Face Spaces

A Hugging Face Space is a small app, usually built with Gradio, that someone has put online. A public Gradio Space can also be called as an API, which makes it a free API with a model behind it. The list below is fetched live from the Hub's public API when you press a button, so it is always the current ranking, not a snapshot. See the Spaces API guide for how to call one.

Free, with limits. Listing Spaces and opening a public one costs nothing and needs no token. Running a Space uses its owner's computer, and shared GPU Spaces ("ZeroGPU") give anonymous callers only a small daily quota; more comes with a free account or a paid plan. Never put your own Hugging Face token in a web page. The list is whatever is popular, unfiltered, so a few Spaces may not suit every audience; each card links to its own page.
