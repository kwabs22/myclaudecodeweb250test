# Creative media

Memes, music, social media and storytelling: reference documents, two lists of GitHub projects, a small music quiz and a demo dashboard.

| Folder | What is in it |
|---|---|
| [`memes/`](memes/) | A meme dictionary, plus two country-by-country dictionaries of memes, slang and viral content. Reference text only. |
| [`music/`](music/) | [50 music production repositories](music/50-music-production-repos.md), music theory libraries, a piano roll guide with 87 concepts, a [VST and sound design guide](music/vst/VST_AND_MUSIC_THEORY_GUIDE.md), and 200 guitar and piano theory questions that power the [Music Theory Quiz](music/theory-quiz/index.html). |
| [`social-media/`](social-media/) | Learning resources on trending topics, and the [Social Trends Hub](social-media/trending-topics-ui/UI_README.md) dashboard (sample data, with links to the real sources). |
| [`story-generation/`](story-generation/) | One long guide to story generation methods and tools, from Ink and Twine to language models. |

A few things to know:

- The music theory question sets are written as questions with answers, so the quiz page is a flashcard deck: it does not mark typed answers.
- The two repository lists (music production, social media) came from research chats. Each `owner/name` line links to GitHub, but the names were not all checked, so a few may no longer exist.
- The 3D game development index used to sit in `story-generation/` by mistake. It is now [game-development/README.md](../game-development/README.md).
