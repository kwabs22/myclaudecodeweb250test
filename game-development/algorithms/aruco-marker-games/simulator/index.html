ArUco Simulator

The 50 marker games expect a camera and a marker detector to tell them which markers are in view and where. This page plays the detector: pick a game, then put its markers on the table below the picture and drag them around. Each placed marker is reported to the game ten times a second, the way a camera would, and taking one off the table tells the game it is gone.

Marker table

Click a marker below to put it on the table, drag it to move it, and use the arrow keys or the slider to turn it. Double-click a marker on the table, or click it below again, to take it off.

Log

The game scripts are the ones in aruco-marker-games, run unmodified. The page supplies a camera, a light, a root object, stand-ins for prefab assets, and the marker detector: a marker is reported by calling the script's onMarkerDetected(id, pose) (or onMarkerFound) with pose.position as a position on the table (in metres, as the games assume: the table is 2 metres across, so its edge is at 1) and pose.rotation as the turn about the vertical. Scripts without a lost handler simply stop hearing about the marker. The camera is switched off, so the one script that asks for it gets a refusal. Engine: PlayCanvas 1.77.
