## 🛠️ Using the Data Files

### JSON Files

**Load in JavaScript:**
```javascript
const fs = require('fs');
const data = JSON.parse(fs.readFileSync('playcanvas_top_functions.json'));
```

**Load in Python:**
```python
import json
with open('playcanvas_top_functions.json', 'r') as f:
    data = json.load(f)
```

### CSV Files

**Load in Excel/Google Sheets:**
- File → Open → Select .csv file

**Load in Python:**
```python
import pandas as pd
df = pd.read_csv('top_20_functions_summary.csv')
```

**Load in JavaScript:**
```javascript
const csv = require('csv-parser');
const fs = require('fs');

fs.createReadStream('top_20_functions_summary.csv')
  .pipe(csv())
  .on('data', (row) => console.log(row));
```
