🚨 CAMERA PERMISSION TROUBLESHOOTING 🚨

═══════════════════════════════════════════════════════════

ISSUE: "Permission is immediately denied"

This happens because browsers block camera access for security.
Let's fix it!

═══════════════════════════════════════════════════════════

✅ SOLUTION 1: Use Local Server (BEST FIX)

Browsers need "localhost" or "https" to allow camera.

STEPS:

1. Open terminal/command prompt

2. Navigate to folder:
   cd anatomy-viz-web

3. Start server:

   Python (if you have it):
   python -m http.server 8000

   OR Python 3:
   python3 -m http.server 8000

   OR Node.js:
   npx http-server -p 8000

4. Open browser:
   http://localhost:8000

5. Allow camera when asked!

═══════════════════════════════════════════════════════════

✅ SOLUTION 2: Chrome Specific Settings

If using Chrome directly with file://

1. Close ALL Chrome windows

2. Reopen Chrome with flag:

   Windows:
   chrome.exe --allow-file-access-from-files --unsafely-treat-insecure-origin-as-secure="file://"

   Mac:
   open -a "Google Chrome" --args --allow-file-access-from-files

   Linux:
   google-chrome --allow-file-access-from-files

3. Open index.html

4. Camera should work now!

═══════════════════════════════════════════════════════════

✅ SOLUTION 3: Firefox Settings

1. Open Firefox
2. Type in address bar: about:config
3. Accept warning
4. Search for: media.navigator.permission.disabled
5. Set to TRUE
6. Open index.html
7. Camera should work!

📱 ON MOBILE (Android/iPhone):

ANDROID:
1. Chrome Settings → Site Settings → Camera
2. Find the file/site
3. Change to "Allow"
4. Refresh page

IPHONE:
1. Settings → Safari → Camera
2. Enable camera access
3. Settings → Privacy → Camera → Safari → ON
