# Claude Code Web Testing Repository

**Repository merged from 30 Claude Code branches**
**Live site**: the [Session Atlas](https://kwabs22.github.io/myclaudecodeweb250test/) turns this repository into a website: a 3D map of every file, a page for each document and code file, and the interactive pages listed below.
**Date**: merged 2025-12-25 (completed 2026-09-27, see [`MERGE_COMPLETE.md`](./MERGE_COMPLETE.md)); content has been added since, including a lot of review and fixing
**Origin**: the 30 original branches came from Claude Code sessions run in Q4 2025 as part of a $250 credit test. Merging them, auditing the merge, and building the Session Atlas site was done in one later session that was part of a $100 free-credit test. Pages, quizzes and checks added since were built in follow-up sessions.

> **Try this first:** [Combinatorics in the real world](https://kwabs22.github.io/myclaudecodeweb250test/learning-resources/mathematics/real-world/index.html), a 3D map of everyday counting problems (schedules, teams, hobby groups, relationships and remixes) with live numbers.
