Edge detection

An edge is a place where brightness changes quickly. Each method below slides a small grid of weights (a kernel) over the picture and adds up weighted neighbours, which measures how steeply brightness rises there. Pick a method, change the image, and click any pixel in the left picture to see the arithmetic for that spot.

How the steps fit together

  1. Make it grey. Edges are about brightness, so colour is reduced to one number per pixel (0.299 R + 0.587 G + 0.114 B).
  2. Blur a little. Noise looks like tiny edges everywhere. A Gaussian blur averages it away, at the cost of softening real edges.
  3. Measure the slope. One kernel measures change left to right (Gx), another top to bottom (Gy). Strength is √(Gx² + Gy²) and direction is atan2(Gy, Gx).
  4. Decide what counts. A threshold keeps pixels whose strength is large enough. Canny also thins the ridge to one pixel and keeps weak edges only if they touch strong ones.

The methods compared

MethodKernel sizeGood atWeak at
Roberts cross2×2Speed, fine detailNoise, since it averages almost nothing
Prewitt3×3Simple, even smoothingDiagonal accuracy
Sobel3×3The standard first choice: a little smoothing built inEdges are several pixels thick and need a threshold
Scharr3×3More accurate direction than SobelSlightly more noise-sensitive
Laplacian3×3Finds edges in every direction at once, as zero crossings of the second differenceVery noisy without blurring first, and gives no direction
CannyBlur + SobelThin, connected outlines with fewer false edgesThree settings to tune (blur, low, high)

Why a kernel with a 1-2-1 column?

The Sobel x kernel is a column of weights [1, 2, 1] (smooth along the edge) multiplied by a row [−1, 0, 1] (difference across it). So it first averages three rows and then takes a difference, which is why it resists noise better than a plain difference. Scharr uses [3, 10, 3] for the smoothing part. The numbers in each kernel sum to zero, so a flat region gives zero response.

The logic is in edges.js and is checked by check.js (node check.js): the kernels, a hand-padded reference, the response to a step edge (Sobel 4h, Prewitt 3h, Scharr 16h), the response to a ramp, the Canny outline of a square, and more. See the README for how to use these on real images with OpenCV.
