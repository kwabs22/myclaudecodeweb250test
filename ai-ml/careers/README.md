## The roadmap at a glance

[The repository guide](ai-engineer-roadmap/ai-engineer-roadmap-github-repos.md) is about 90 KB (two to three hours to read) and maps more than 60 GitHub repositories to six phases:

1. **Mathematics and programming fundamentals**
2. **Machine learning and deep learning** (PyTorch, TensorFlow)
3. **Generative AI** (LLMs, RAG, LangChain, vector databases)
4. **MLOps and production** (Docker, Kubernetes, cloud platforms)
5. **Advanced topics** (transformers, fine-tuning, PEFT, LoRA)
6. **Capstone projects and portfolio building**

It also has three learning paths (fast track 12 months, balanced 18, thorough 24), project ideas and capstone requirements for each phase, a skills checklist, a week-one action plan, and certification and community resources. It is for anyone who wants to become an AI engineer, from complete beginners to developers moving into AI. It follows the ["God Tier" AI Engineer Roadmap video](https://www.youtube.com/watch?v=ewLJUvQbOu4).

The quizzes test the first two phases: [Phase 1](ai-engineer-roadmap/quiz-app.html) and [Phase 2](ai-engineer-roadmap/phase2-quiz-app.html).
