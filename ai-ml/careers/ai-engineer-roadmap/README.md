# AI engineer roadmap: guide and quizzes

A repository guide for a six-phase AI engineer roadmap, a 1,000-question quiz for each of the first two phases, and a hand-written quiz for the third.

## Where each phase stands

| Phase | Topic | Quiz | Questions | Read this |
|---|---|---|---|---|
| 1 | Maths and programming fundamentals | [Phase 1 quiz](quiz-app.html) | 1,000: linear algebra 200, Python 200, calculus 150, probability and statistics 150, SQL 150, data structures and algorithms 150 | [PHASE1_README.md](PHASE1_README.md) |
| 2 | Machine learning and deep learning | [Phase 2 quiz](phase2-quiz-app.html) | 1,000: deep learning 500, classical ML 350, prompt engineering 150 | [PHASE2_README.md](PHASE2_README.md) |
| 3 | Generative AI | [Phase 3 quiz](phase3-quiz-app.html) | 96, hand-written: OpenAI API, Hugging Face, embeddings and vector databases, RAG, agents | [PHASE3_README.md](PHASE3_README.md) |
| 4 to 6 | MLOps, advanced topics, capstone | none yet | none | The [repository guide](ai-engineer-roadmap-github-repos.md) covers them |

The three READMEs are the same kind of document: how the quiz works, how the questions are split, how to study with it, and how to regenerate the question bank.

## Good to know

- Each question stores its correct answer as the first option. Both quiz pages shuffle the options when they load, so the answer is not always A.
- The Phase 1 and Phase 2 questions were generated by script from templates, and many repeat. Counting a question once however often it comes back, Phase 1 has about 170 different questions (for example, the calculus section is 8 questions repeated across 150 slots, and the Python section is 4) and Phase 2 has about 80. Some wrong options are also generic placeholders. Use those two quizzes for practice, not as an exam, and expect to see the same question more than once in a long session. The Phase 3 questions were written by hand, with real distractors and explanations.
- There is no quiz for Phases 4 to 6 yet.
