# AI engineer roadmap: guide and quizzes

A repository guide for a six-phase AI engineer roadmap, and a 1,000-question quiz for each of the first two phases.

## Where each phase stands

| Phase | Topic | Quiz | Questions | Read this |
|---|---|---|---|---|
| 1 | Maths and programming fundamentals | [Phase 1 quiz](quiz-app.html) | 1,000: linear algebra 200, Python 200, calculus 150, probability and statistics 150, SQL 150, data structures and algorithms 150 | [PHASE1_README.md](PHASE1_README.md) |
| 2 | Machine learning and deep learning | [Phase 2 quiz](phase2-quiz-app.html) | 1,000: deep learning 500, classical ML 350, prompt engineering 150 | [PHASE2_README.md](PHASE2_README.md) |
| 3 to 6 | Generative AI, MLOps, advanced topics, capstone | none yet | none | The [repository guide](ai-engineer-roadmap-github-repos.md) covers them |

The two READMEs are the same kind of document: how the quiz works, how the questions are split, how to study with it, and how to regenerate the question bank.

## Good to know

- Each question stores its correct answer as the first option. Both quiz pages shuffle the options when they load, so the answer is not always A.
- The questions and answers were generated by script from templates. Some wrong options are generic placeholders, so use the quizzes for practice, not as an exam.
- Phase 3 is named as the next step in the Phase 2 README, but no Phase 3 quiz exists yet.
