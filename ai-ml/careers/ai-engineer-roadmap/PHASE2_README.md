## 🚧 Common Pitfalls

### Classical ML
❌ Not scaling features
❌ Using accuracy for imbalanced datasets
❌ Forgetting train/test split
✅ Use StandardScaler, F1-score, and cross-validation

### Deep Learning
❌ Too high learning rate
❌ Not using GPU acceleration
❌ Overfitting on small datasets
✅ Use learning rate schedules, GPU, and augmentation

### Prompt Engineering
❌ Vague instructions
❌ No examples for complex tasks
❌ Ignoring token limits
✅ Be specific, provide examples, and stay concise
